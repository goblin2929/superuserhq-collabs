# Old Role vs New Role: Marketing in the Harness Era

Research compiled for Tiket workshop — April 2026

---

## The Role Map

| Old Title | New Title | What Changed |
|---|---|---|
| Content Manager | **GTM Engineer** | Writing blogs → building revenue systems |
| Campaign Ops Manager | **AI Campaign Orchestrator** | Launching campaigns → defining constraints for agents that run campaigns |
| CRM Admin | **Autonomous CRM Agent Supervisor** | Field mappings → overseeing exception handling and policy design |
| Marketing Analyst | **Agent-Driven Insight Curator** | Pulling data (70% of time) → curating strategic insights from agent-generated analysis |
| Marketing Automation Specialist | **Workflow Architect** | Building Zapier flows → designing self-healing systems and AI permission governance |
| Ops Coordinator | **Marketing Agent Product Manager** | Chasing approvals → managing agent roadmaps and evaluating agent performance |
| Marketing Generalist | **Gen Marketer** (Emily Kramer) | Jack-of-all-trades → AI-orchestrating generalist who runs end-to-end campaigns solo |
| Prompt Engineer | **Harness Engineer** | Crafting prompts → designing environments, constraints, feedback loops for AI agents |
| SDR / BDR | **GTM Engineer (RevOps)** | Cold outreach → building automated prospecting systems |

## The Three-Era Framework

| Era | Focus | Key Question |
|---|---|---|
| **2022-2024: Prompt Era** | Better prompts | "How do I write a better prompt for a better blog post?" |
| **2025: Context Era** | Better context | "How do I give AI enough context about my brand and goals?" |
| **2026: Harness Era** | Better systems | "How do I build the environment, constraints, and feedback loops that let agents run reliably?" |

---

## Skills That Matter MORE Now

1. **Workflow/System Design** — not "write this email" but "design the system that writes, sends, tests, and optimizes emails"
2. **Agent Orchestration** — managing multiple AI agents, knowing when human judgment vs automation
3. **Harness/Environment Design** — constraints, feedback loops, validation systems
4. **Data Pipeline Thinking** — how data flows between systems
5. **ROI Measurement Discipline** — Clay evaluates GTM Engineers on "commercial mindset"
6. **Technical Fluency (not expertise)** — "willing to learn by tinkering" (Clay), "basic syntax, debug API integrations" (Toast)
7. **Deterministic vs Probabilistic Thinking** — what's predictable vs what needs guardrails

## Skills Becoming LESS Important

1. Manual content production (AI drafts, human edits/curates)
2. Single-channel mastery (value shifts to cross-channel orchestration)
3. Tool-by-tool expertise (system design > UI muscle memory)
4. Data pulling / dashboard building (agents handle 70% of this)
5. Syntax memorization / manual configuration
6. Repetitive reporting
7. Campaign setup mechanics (HubSpot AI: 4 hours → 12 minutes)
