Cheatsheet

The Agentic Workflow Toolbox

A non-exhaustive but opinionated map of the tools you'll actually hear people mention in 2026. Grouped by what they do, not by who sells them. If a tool isn't here, it's probably either too early or too narrow to matter yet.

01

Runtimes & Agent Platforms

Where the agent actually runs. This is the foundational layer — pick one of these first.

ToolVendorWhat it isBest forPricing
Claude Cowork Anthropic Chat-based AI workspace with projects, skills, and shared context Ad-hoc work, drafting, research, anyone who lives in a browser Paid SaaS
Claude Code Anthropic Terminal-based agentic coding and workflow tool with skills, agents, hooks Structured workflows, team repos, anyone willing to use a terminal Paid SaaS
Managed Agents Anthropic Anthropic-hosted autonomous agents that run in the cloud for minutes to hours Scheduled or triggered work, no laptop required Paid SaaS
OpenClaw Open-source Self-hosted runtime for Claude agents, multi-model routing, 24/7 autonomous execution Data residency, scale, cost control, full infra ownership OSS, self-host
LangGraph LangChain Graph-based orchestration framework for multi-agent / multi-step pipelines Engineers building complex branching workflows; not for non-tech teams OSS + cloud
Cursor / Windsurf Cursor, Codeium AI-native IDEs with embedded agents for code editing Developers who live in an editor — overlap with Claude Code for dev tasks Paid SaaS
02

Research & Scraping

How your agent reads the web. If Claude needs to look at 50 pages, one of these is probably doing it.

ToolVendorWhat it isBest forPricing
Firecrawl Firecrawl LLM-friendly web scraper — turn any URL into clean markdown, with crawling and extraction modes Turning real-world webpages into agent-readable input OSS + paid
Tavily Tavily Search API built for AI agents; returns synthesized answers with citations Giving agents a "search the web and come back with an answer" primitive Paid API
Exa Exa Neural search API designed for finding semantically similar content Finding similar pages, competitor analysis, content gaps Paid API
Perplexity API Perplexity Retrieval-augmented chat endpoint — Perplexity's core product as an API call When you want "what's the latest on X" and need citations in the response Paid API
Browserbase Browserbase Hosted headless browser as a service — Playwright/Puppeteer in the cloud Agents that need to interact with pages that require real browser rendering Paid API
03

Orchestration & Pipelines

How you schedule, trigger, and connect agents to the rest of your stack. This is where most non-technical teams quietly live.

ToolVendorWhat it isBest forPricing
n8n n8n Open-source node-based workflow builder with 500+ integrations and AI agent nodes Non-engineers building real pipelines. Self-hostable. The best free option. OSS + cloud
Zapier Zapier No-code automation platform with the biggest app integration library in the world Quick wins, maximum app coverage, no infra. Pricey at scale. Paid SaaS
Make.com Make (Integromat) Visual workflow builder with more logic depth than Zapier, less than n8n Middle ground for teams who want visual drag-drop but more power than Zapier Paid SaaS
Temporal Temporal.io Durable execution platform for long-running, reliable workflows Engineering teams running multi-day workflows that must survive failures OSS + cloud
Trigger.dev Trigger.dev Code-based job runner optimized for long-running AI workflows Developer teams who want scheduled/triggered AI jobs without running infra Paid SaaS
04

Memory & State

How agents remember across sessions. Most teams ignore this until they're already in pain.

ToolVendorWhat it isBest forPricing
Letta (MemGPT) Letta Stateful memory system for agents with hierarchical memory and long-term recall Agents that need to remember personas, preferences, history over weeks OSS + cloud
Zep Zep Long-term memory service for AI apps with search and semantic recall Chat products where the agent needs to remember the user across sessions Paid SaaS
Mem0 Mem0 Open-source personalization / memory layer that learns from user interactions Apps that want "ChatGPT remembers you" personalization without building from scratch OSS + cloud
05

Observability & Cost Control

How you see what agents are doing, what they're spending, and where they're failing. Non-negotiable once you're running more than one agent in production.

ToolVendorWhat it isBest forPricing
Langfuse Langfuse Open-source LLM observability: traces, costs, evals, user feedback in one view Teams that want self-hostable observability with a good free tier OSS + cloud
LangSmith LangChain Managed observability + eval platform for LLM apps Teams already using LangChain/LangGraph Paid SaaS
Helicone Helicone Drop-in proxy that logs every LLM call with cost, latency, and tracing "Set-and-forget" observability with minimal setup OSS + cloud
Braintrust Braintrust Eval-first platform for testing prompt/agent quality over time Teams that care about quality regressions and want to ship with confidence Paid SaaS
06

Interface & Distribution

How your team actually clicks on an agent. Agents that require a terminal won't be used by sales.

ToolVendorWhat it isBest forPricing
Streamlit Snowflake Python-based framework for turning scripts into interactive web apps fast Internal tools for non-technical users — one Python file, one URL OSS + cloud
Gradio Hugging Face Similar to Streamlit, stronger for ML demos and agent front-ends Demo pages and quick-and-dirty interfaces for agent outputs OSS
Vercel AI SDK Vercel TypeScript library for streaming LLM responses in Next.js/React apps Engineering teams building production-grade AI web apps Free OSS
Retool Retool Low-code internal tools platform with LLM components Back-office internal apps where you'd otherwise build a React dashboard Paid SaaS
Slack / Teams bots any provider Running your agent as a bot in the chat tool your team already lives in The most-underrated interface: zero onboarding, 100% adoption Varies
07

The Short Decision Guide

The honest version — what most teams should actually pick.

Your situationWhat to reach for
Starting out, no infra, no engineersCowork + Zapier or n8n cloud
You have a few devs / willing-to-learn marketersClaude Code + n8n + Firecrawl
You need overnight / scheduled autonomous workManaged Agents or Trigger.dev
Data residency matters / regulated industryOpenClaw (self-hosted) + Langfuse (self-hosted)
You want the cheapest path to production observabilityHelicone or Langfuse
You want non-technical teammates to actually use the agentsSlack/Teams bot + Retool for edge cases
You need to remember users across sessionsZep or Letta
You need to search the web for an agentTavily (answer) or Exa (discovery) or Firecrawl (crawl)
90% of teams only need 4 of these: a runtime, a scraper, an orchestrator, and observability.
Everything else is optional and most of it is premature. Start with four, add the fifth when you've earned the scar.
